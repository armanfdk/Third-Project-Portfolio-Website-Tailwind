# Professional Portfolio Website

A modern, fully responsive portfolio website built with **Tailwind CSS** and **Vanilla JavaScript**, designed with a sleek dark theme and smooth animations. This project was built as part of my front-end development learning journey.

## 🚀 Live Demo

https://armanfdk.github.io/Third-Project-Portfolio-Website-Tailwind/

## 🛠️ Tech Stack

*   **HTML5** - Semantic structure
*   **Tailwind CSS** - Utility-first styling for rapid UI development
*   **Vanilla JavaScript** - Interactive components and animations
*   **FontAwesome** - Local icons for a lightweight, offline-friendly experience

## ✨ Features

*   Fully responsive design (Mobile-first approach)
*   Modern Dark UI with custom accent colors
*   Smooth hover effects and interactive animations
*   Custom developer footer with social media links
*   Local asset management for maximum performance
